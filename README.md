# AI-Assisted Workflow Case Studies

Practical case studies showing how I use AI-assisted tools to define requirements, investigate problems, review outputs, identify failures and verify working solutions.

My role in these projects is workflow design, product ownership, quality evaluation and AI-tool orchestration. I do not present AI-generated or AI-assisted code as independently hand-coded work.

## Planned case studies

1. Photoshop frame geometry and visual QA
2. Photoshop automation workflow
3. Reusable buyer-document generation and quality checks

## Principles

- Clear requirements before implementation
- Human review of AI-generated outputs
- Measurable acceptance criteria
- Failed results are documented rather than hidden
- Real-software verification where relevant
- No private client data or proprietary SC8PE production assets
